# DataSkein v0.1.7

This release improves the first useful minute in the workspace and fixes several result-trust issues found during a parallel product and technical review.

## What changed

- Adds an outcome-first local file drop zone, safe sample path, resumable first-result guide, real operation progress, offline status, and contextual recovery actions.
- Preserves each source's in-session recipe, chart setup, dashboard, and active tab when switching between loaded datasets.
- Adds the previously documented visual column-selection recipe step.
- Completes keyboard navigation for workspace tabs and verifies the compact mobile workspace without overflow or console errors.
- Restricts chart measures to numeric columns and prevents stale chart queries from being pinned after rapid changes.
- Keeps line and area dashboard exports faithful to their selected type, including a correct zero baseline for negative values.
- Removes the misleading scatter option, which did not have a real numeric x-axis.
- Labels columns beyond the 80-column profiling cap as not profiled instead of showing invented zero counts.

## Verified boundaries

- Source files still remain in the browser session and are not uploaded by DataSkein.
- The 1 GB per-file refusal, 1 GB query memory setting, 250-row preview cap, 80-column profiling cap, and 100-group chart cap are unchanged.
- CSV, JSON, JSONL, real Parquet, malformed input, extension spoofing, formula-safe CSV export, offline use, mobile layout, accessibility, and a 64 MiB CSV were exercised in the browser suite.
