# DataSkein v0.1.1

This patch makes the downloadable static build reproducible across Windows and
Linux.

## Fixed

- Removed the production source map, which embedded package-manager paths that
  differ by operating system.
- Normalized text files before deterministic ZIP creation.
- Advanced the service-worker cache version so existing visitors receive the
  corrected build.

All formatting, linting, type, unit, coverage, production build, dependency
audit, accessibility, format, 64 MiB input, and browser journey gates run again
for this tag.
