# DataSkein v0.1.3

DataSkein v0.1.3 is an accessibility patch discovered during the public production smoke test.

## Fixed

- Give the visual workflow illustration valid image semantics.
- Remove an unsupported ARIA label from the visible DataSkein wordmark.
- Reject prohibited ARIA attributes in the landing-page accessibility regression test.

The product scope, data handling, release artifact format, and browser compatibility are unchanged from v0.1.0.
