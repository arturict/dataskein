# DataSkein v0.1.9

This patch fixes a value-rendering problem found during the production smoke
test of v0.1.8.

## Fixed

- DuckDB `DECIMAL` values now use the scale declared in the Arrow schema.
- A value stored as the unscaled integer `125` with scale `2` is shown as
  `1.25` instead of Apache Arrow's internal 32-bit word array.
- Negative values, leading fractional zeroes, and trailing decimal zeroes keep
  their exact display scale.

## Verification

The real 100,000-row DuckDB browser fixture now asserts a visible `1.25`
decimal cell in addition to the read-only catalog, 250-row bounded preview,
disabled view execution, qualified SQL export, mobile layout, accessibility,
spoof rejection, and no cross-origin requests.
