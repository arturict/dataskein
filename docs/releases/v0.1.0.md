# DataSkein v0.1.0

The first public release focuses on a single job: turn recurring local exports
into a visible transformation recipe and an answer that can be reviewed.

## Highlights

- Open CSV, TSV, JSON, JSONL, NDJSON, and Parquet files locally in the browser.
- Profile columns and inspect a capped, virtualized preview.
- Add visual filters, sorts, column selection, and joins across local sources.
- Inspect the generated DuckDB SQL at every step.
- Build accessible charts and small in-session dashboards.
- Export formula-neutralized CSV, a source-fingerprinted SQL recipe, or a
  standalone dashboard containing aggregate data.
- Use the app without an account, analytics, cookies, or an upload endpoint.

## Safety and limits

The release refuses files above 1 GB, applies a 1 GB query memory setting, uses
one browser worker and one query thread, caps previews at 250 rows, and caps
chart aggregates at 100 groups. These controls do not guarantee that every
workload below 1 GB succeeds. Browser WebAssembly limits, very wide schemas,
deep JSON, and expensive joins may fail earlier.

CSV exports prefix formula-like text with an apostrophe and quote every field.
Obvious content and extension mismatches are rejected before DuckDB opens the
file.

## Verification

The release workflow runs formatting, linting, strict type checks, unit and
coverage tests, a production build, dependency audit, accessibility checks, and
browser tests. The browser suite includes a 64 MiB CSV, malformed JSON, spoofed
Parquet, the Apache Parquet interoperability fixture, formula payloads, and a
no-cross-origin-request assertion.

The downloadable ZIP is a deterministic static build. Verify it with the
matching `.sha256` file, extract it, and serve the directory with SPA fallback
for `/app`.
