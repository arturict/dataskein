# DataSkein v0.1.2

This patch completes the reproducible static archive work.

## Fixed

- Encoded the deterministic ZIP timestamp as the same DOS-local time on every
  build machine, removing the last timezone-dependent metadata bytes.
- Advanced the service-worker cache version so existing visitors receive the
  corrected build.

The extracted `v0.1.1` files were already identical across Windows and Linux.
This release also makes the complete ZIP checksum identical across those
platforms.
