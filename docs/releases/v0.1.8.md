# DataSkein v0.1.8

This release follows one concrete r/DuckDB request with the narrowest useful
database-file workflow. It also ships the CSV import X-ray and explicit recovery
controls that were already complete locally after v0.1.7.

## What changed

- Open a local `.duckdb` file and browse its schemas, base tables, and views.
- Verify the database attachment as read-only before showing its catalog.
- Show column counts and approximate row metadata for base tables.
- Inspect a chosen base table in the normal DataSkein workspace.
- Limit automatic database inspection to column discovery and 250 preview rows.
- List persisted views without executing them because stored view SQL may refer
  to external sources.
- Preserve the database filename, SHA-256 fingerprint, qualified table name,
  and explicit `TYPE DUCKDB, READ_ONLY` attachment in exported SQL.
- Show detected CSV dialect details and retry failed CSV imports with explicit
  delimiter, header, encoding, or all-text settings.

## Deliberate limits

This is not a general DuckDB client. There is no arbitrary SQL console, write
path, database administration surface, or automatic execution of persisted
views. Opening a database table does not trigger a full count or profile scan.
Charts, sorts, filters, joins, and exports remain explicit actions and may scan
more data.

The browser still refuses individual files above 1 GB. Wide schemas, encrypted
databases, uncheckpointed WAL state, newer incompatible storage versions, and
browser memory pressure can fail below that limit.

## Verification

The browser suite uses a real checkpointed DuckDB 1.4.3 fixture containing two
schemas, two base tables, one persisted view, and a 100,000-row table. It checks
catalog listing, disabled view execution, bounded startup inspection, DuckDB
extension spoofing, accessibility, and the absence of cross-origin requests.
The existing 64 MiB CSV, real Parquet, malformed input, formula-safe export,
responsive layout, offline, and complete sample-journey coverage remain in the
release gates.
