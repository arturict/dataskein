# DataSkein v0.1.4

DataSkein v0.1.4 fixes the public workspace route discovered during the post-deployment smoke test.

## Fixed

- Serve `/app` and `/app?sample=1` through the Vercel SPA shell instead of returning 404.
- Keep nested `/app/*` workspace routes on the same shell.
- Add a hosting configuration regression test for the production route contract.

The product scope, local-first data handling, and release artifact format are unchanged from v0.1.0.
