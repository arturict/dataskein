# Naming decision

Research snapshot: 29 July 2026.

## Final name: DataSkein

A skein is a length of thread arranged together. The name supports the product
idea of following a visible thread from source files through transformations to
an answer. It is distinctive enough to search, pronounceable in English, and
does not imply a full spreadsheet or BI platform.

## Checks performed

Exact and near-exact searches covered:

- GitHub repository names and code search,
- npm, PyPI, and crates.io package pages,
- general web search,
- `.com`, `.app`, and `.dev` domain registration availability,
- indexed WIPO Global Brand Database, EUIPO, and Swissreg results,
- obvious product and company uses in the data-tool category.

Observed result for `DataSkein`:

- no exact GitHub repository result,
- `dataskein` and `data-skein` returned no npm package,
- no exact PyPI or crates.io package,
- no meaningful exact product or company collision in web search,
- no exact indexed mark in the searched trademark databases,
- `dataskein.app` and `dataskein.dev` were available at USD 10.98 each through
  the live Namecheap check,
- `dataskein.com` was unavailable.

No domain was purchased and no money was spent. The production site uses the
free Vercel subdomain.

## Rejected candidates

### DataCanvas

Rejected because the term has numerous exact GitHub repositories, an existing
PyPI package, broad product and company uses, and unavailable `.app` and `.dev`
domains. It is descriptive and difficult to own in search.

### Tableloom

Rejected because exact or near-exact GitHub projects and an existing Tabloom
application create avoidable confusion. Most attractive domains were also
unavailable.

## Legal caveat

This was a practical collision screen, not a professional trademark clearance
or legal opinion. Trademark databases have jurisdiction, class, spelling, and
indexing limitations. A future paid offering, company rename, or domain purchase
should repeat the search and obtain qualified advice if the risk justifies it.
